## 常见问题

**外贸网站一定要用海外服务器吗？**
不一定，但用境内服务器必须备案，海外客户访问也会变慢。做外贸更常见的做法是选香港、新加坡、硅谷这类节点，免备案，也更接近目标市场。

**2 核 2G 的配置够用吗？**
官方给的参考是日均约 1500 访问量，刚上线的外贸独立站通常远低于这个数字。图片压缩好、视频用外链，比加配置更有效。

**能绑定自己注册的域名吗？**
可以。一个套餐支持绑定 5 个域名，也支持部署 SSL 证书。

**和 WordPress 比，哪个好？**
看你要什么。要自由改代码、装各种插件、做复杂功能，WordPress 更合适，代价是自己维护。要一个上线快、有服务商管售后的多语言企业官网，云官网AI建站更省事，代价是功能边界固定。

**以后想换系统，数据能迁走吗？**
从老产品迁移到新产品有官方支持。至于自行导出换别的系统，官方页面没有给出通用导出承诺，签长约之前最好先问清楚客服。
